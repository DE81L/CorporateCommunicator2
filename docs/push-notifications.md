# Push-уведомления и Email

Реализована отправка уведомлений через Firebase Cloud Messaging. Если для пользователя нет токена или попытка доставки завершилась ошибкой, сообщение отправляется на его электронную почту.

## Переменные окружения
- `FCM_SERVER_KEY` — ключ сервера Firebase.
- `SMTP_HOST` и `SMTP_PORT` — параметры подключения к SMTP.
- `MAIL_FROM` — адрес, указанный в поле From.
