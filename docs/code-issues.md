# Code Issues

Этот файл содержит список проблем, обнаруженных при первичном анализе репозитория.

1. В репозитории присутствует файл `.env` с реальным `SESSION_SECRET`, что создаёт риск утечки секретов.
2. В каталоге `server/uploads` лежат пользовательские данные и файл `85.plain`, содержащий копию `.env` и другую конфиденциальную информацию.
3. В проект добавлены скомпилированные артефакты (`client/dist`, директория `build`), их лучше исключить из репозитория.
4. Одновременно используются два lock-файла (`pnpm-lock.yaml` и `package-lock.json`), что может вызвать несоответствие зависимостей.
5. Каталог `literal_copy_of_doom` увеличивает размер репозитория и не относится к основной функциональности проекта.
6. `.gitignore` не исключает чувствительные и сгенерированные файлы, стоит дополнить его правилами.
