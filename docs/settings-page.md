# Страница настроек профиля

Форма `SettingsPage` позволяет пользователю изменить имя, email и загрузить новый аватар. Для загрузки используется роут `/api/user/avatar`, принимающий файл через `multer` и сохраняющий его в папку `server/uploads/avatars`.

После отправки формы профиль обновляется и страница перезагружается.
