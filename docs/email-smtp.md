# Настройка отправки почты через Gmail SMTP

Модуль `server/mail.ts` использует `nodemailer` и сервис Gmail для отправки писем.

## Переменные окружения

- `SMTP_USER` — адрес Gmail, с которого отправляются письма.
- `SMTP_PASS` — пароль приложения для указанного аккаунта.

После установки переменных можно вызвать функцию `sendMail(to, subject, text)`
для отправки простого текстового письма.
