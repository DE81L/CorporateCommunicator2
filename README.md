# Corporate Communicator 2

Проект состоит из нескольких пакетов: серверной части, клиента и Electron-оболочки.

## Установка

```bash
pnpm install
```

## Запуск в разработке

```bash
pnpm run dev
```

## Сборка

```bash
pnpm run build
```

## Запуск тестов

Информация о тестах описана в [docs/test-run.md](docs/test-run.md). Кратко:

```bash
pnpm exec jest
```
